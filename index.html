A full-stack business system for companies with several shops and a warehouse. It tracks stock, sales, purchases, customers, expenses and profit in one place.

Lotus Spa AI Assistant: Booking Chatbot

A chatbot that answers customers only from the spa's real data and books appointments inside the chat. A free demo mode runs in any browser; AI mode uses OpenAI with function calling.

  • Books step by step: treatment, day, free time, name, phone, then confirm
  • AI mode calls 5 tools for prices, hours and free times, so it never makes things up
  • API key kept on the server, rate limiting, and protection against prompt injection
  • 31 unit tests plus Playwright browser tests, running on GitHub Actions
  • JavaScript
  • Node.js
  • OpenAI API
  • Function calling
  • Playwright
