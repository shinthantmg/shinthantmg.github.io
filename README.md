# shinthantmg.github.io

Personal portfolio of **Shin Thant Maung**, ICT student at Rangsit University, Thailand.

**Live site:** https://shinthantmg.github.io

## Sections

- **Hero:** photo, short introduction and internship availability (from January 2027, remote)
- **Internship roles:** Web Developer, Software Developer, AI Automation, Chatbot Developer, QA Tester
- **Projects:** [SmartStock](https://github.com/shinthantmg/SmartStock) and [Lotus Spa Bangkok](https://github.com/shinthantmg/spa-salon-booking)
- **Skills, About and Contact**

## Built with

Plain HTML, CSS and JavaScript in a single `index.html`, with no frameworks or build step. It's responsive, supports light and dark mode, and is hosted for free on GitHub Pages.

## Updating

- **Add a project:** copy one `<article class="project">` block in `index.html` and change the text and links.
- **Change skills:** edit the `skills` list in the `<script>` at the bottom of `index.html`.
- **Change the photo:** replace `assets/shin-thant-maung.jpg` with a square image of the same name.
